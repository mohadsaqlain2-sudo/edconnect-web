# Phase 5 — Online Classes, Enrollment and Live Jitsi Rooms

**Project:** EduConnect — Laravel 12.70.2 / Bootstrap 5.3.8 / Vite 6.4.5  
**Phase:** 5 — live classes (FR-15 … FR-22)  
**Status:** Implemented, built and verified against the full test suite  
**Date:** 31 October 2026

---

## 1. Objective

Deliver the complete online-class workflow on top of Phases 1–4:

- teachers create, list, filter, edit and delete their own classes
- a private, unguessable Jitsi room name generated by the server (never editable)
- students browse upcoming/live classes, search title/subject/teacher and filter by subject or teacher
- students enroll once, unenroll, see “My enrolled classes” and only join while the class is live
- teachers see the enrolled roster and move a class through scheduled → live → completed with confirmation
- the class page embeds Jitsi Meet through the External API with chat, raise hand, tile view, fullscreen and hangup
- a hangup redirects back to the class page with a flash message
- timing hints (“Starts in 2h 15m” / “Live now”) and a scheduler that closes finished live classes
- working Join buttons and correct upcoming counts on both dashboards
- feature tests for CRUD permissions, enrollment rules, join authorization, status transitions and unique room names

No earlier feature was removed. The changes are additive or narrow a rule to the exact Phase 5 behaviour.

## 3. Behaviour details

### Teacher class management (FR-15, FR-16, FR-19)

- `/classes` is teacher-only and lists the authenticated teacher’s own classes, live first, then scheduled, then completed.
- A `status` query parameter filters the list; unknown values are ignored. Pagination keeps the filter in the query string.
- `StoreClassRequest` requires a title, a date (`after_or_equal:today`), a time in `H:i` and a duration of **15–240** minutes. A second check rejects a start time that has already passed today.
- `UpdateClassRequest` keeps the same field rules but deliberately allows a past date, so a teacher can fix a typo in an old class.
- `room_name` and `status` are never accepted from the form. The model generates `educonnect-` plus 20 random characters and loops until the name is unused; the unique index on `classes.room_name` is the final guard.
- `ClassPolicy::update/delete` allows the owning teacher (and administrators for the separate moderation panel). A different teacher gets 403 on edit, update, delete and the student roster.

### Student browsing and enrollment (FR-17)

- `/classes/discover` shows visible classes that are **live now or still ahead**, ordered by date and time, nine per page.
- Search covers the title, the subject and the teacher’s name. Dedicated `subject` and `teacher` filters can be combined, and both dropdowns only offer values that exist in visible classes.
- `/classes/{classRoom}` shows teacher information, schedule, enrolled count, up to eight enrolled students and the Enroll / Unenroll action.
- Enrollment is student-only (route middleware plus a controller guard), uses `syncWithoutDetaching` so a double click cannot duplicate a row, and is refused for completed classes.
- `/student/classes` lists only the current student’s enrollments, live first, then scheduled, then completed.

### Teacher class detail (FR-17, FR-21)

- `/classes/{classRoom}/students` is owner-only and shows every enrolled student with avatar, name and pagination.
- The class page and class cards show status badges everywhere: scheduled = primary, live = danger, completed = secondary.
- Status buttons are generated from `ClassRoom::TRANSITIONS`; the forms carry a `data-confirm` prompt handled by the shared submit handler.

### Status workflow (FR-21)

- The only legal transitions are:
  - `scheduled → live`
  - `live → completed`
  - `completed →` nothing
- A jump, a backward move, or an invalid status value is refused with a flash message or a validation error, never a 500.
- `classes:complete-finished` runs every minute. It selects live classes whose `start + duration` has passed and moves them to completed through the same transition whitelist.

### Join class and Jitsi (FR-18, FR-20, FR-22)

- `/classes/{classRoom}/room` authorizes `ClassPolicy::join`: the owning teacher or an enrolled student. Everybody else receives 403. Hidden classes stay closed to everyone.
- The teacher may open the room at any time. A student who is enrolled but early receives the friendly `classes.not-started` page, not a broken iframe.
- The page carries `data-*` attributes consumed by `resources/js/jitsi.js`:
  - database `room_name`
  - display name, email and absolute avatar URL
  - class title as the Jitsi subject
  - moderator flag
  - leave URL
- The External API is loaded from `config('services.jitsi.script_url')` and the room runs on `config('services.jitsi.domain')`. Both come from `JITSI_DOMAIN` / `JITSI_SCRIPT_URL` in `.env`.
- Toolbar buttons are exactly: microphone, camera, chat, raise hand, tile view, fullscreen, hangup. Chat is Jitsi’s built-in chat.
- The teacher starts unmuted with the camera on; students start muted with the camera off. Both see the prejoin preview.
- Hangup and `readyToClose` both navigate to `/classes/{classRoom}/leave`, which authorizes the user again and redirects to the class page with a success flash.
- `SecurityHeaders` relaxes `X-Frame-Options`, `frame-src` and the camera/microphone permissions only on the room page, using the same configured domain.

### Dashboards (FR-20, FR-29, FR-30)

- The student hero prefers a live class over the next scheduled one; the live card links straight to `/classes/{classRoom}/room`.
- The teacher hero does the same and also offers the confirmed “Start class” transition.
- Upcoming counts use the shared `scopeUpcoming` (scheduled + start still ahead), so a live or completed class is not counted as upcoming.

### `app/Models/ClassRoom.php`

```php
<?php

namespace App\Models;

use Database\Factories\ClassRoomFactory;
use Illuminate\Database\Eloquent\Builder;
use Illuminate\Database\Eloquent\Factories\HasFactory;
use Illuminate\Database\Eloquent\Model;
use Illuminate\Database\Eloquent\Relations\BelongsTo;
use Illuminate\Database\Eloquent\Relations\BelongsToMany;
use Illuminate\Database\Eloquent\Relations\HasMany;
use Illuminate\Support\Carbon;
use Illuminate\Support\Str;

/**
 * A scheduled live class (FR-15 ... FR-21).
 * The class is called ClassRoom because "Class" is a reserved word in PHP;
 * the database table is "classes".
 */
class ClassRoom extends Model
{
    /** @use HasFactory<ClassRoomFactory> */
    use HasFactory;

    // The three possible states of a class.
    public const STATUS_SCHEDULED = 'scheduled';

    public const STATUS_LIVE = 'live';

    public const STATUS_COMPLETED = 'completed';

    public const STATUSES = [
        self::STATUS_SCHEDULED,
        self::STATUS_LIVE,
        self::STATUS_COMPLETED,
    ];

    /**
     * Which status changes a teacher is allowed to make (FR-21).
     * The only accepted workflow is scheduled -> live -> completed. A class
     * can never skip a step, jump backwards, or be reopened after it ended:
     * every button the teacher sees is derived from this map.
     */
    public const TRANSITIONS = [
        self::STATUS_SCHEDULED => [self::STATUS_LIVE],
        self::STATUS_LIVE => [self::STATUS_COMPLETED],
        self::STATUS_COMPLETED => [],
    ];

    /**
     * The table name does not follow the model name, so it is set explicitly.
     *
     * @var string
     */
    protected $table = 'classes';

    /**
     * @var list<string>
     */
    protected $fillable = [
        'teacher_id',
        'title',
        'description',
        'subject',
        'date',
        'time',
        'duration',
        'room_name',
        'status',
        'is_hidden',
        // Set by classes:notify-starting-soon (FR-23).
        'starting_soon_notified_at',
    ];

    protected function casts(): array
    {
        return [
            'date' => 'date',
            'duration' => 'integer',
            'is_hidden' => 'boolean',
            'starting_soon_notified_at' => 'datetime',
        ];
    }

    /**
     * Every class gets an unguessable Jitsi room name, even when it is created
     * from code or a factory instead of the controller (Phase 2).
     */
    protected static function booted(): void
    {
        static::creating(function (ClassRoom $classRoom) {
            if (blank($classRoom->room_name)) {
                $classRoom->room_name = static::generateRoomName();
            }
        });
    }

    /* ---------------------------------------------------------------
     | Relationships
     * --------------------------------------------------------------- */

    /** The teacher who runs the class. */
    public function teacher(): BelongsTo
    {
        return $this->belongsTo(User::class, 'teacher_id');
    }

    /** The enrolled students. */
    public function students(): BelongsToMany
    {
        return $this->belongsToMany(User::class, 'class_enrollments', 'class_id', 'student_id')
            ->withTimestamps();
    }

    /** Raw enrollment rows (used for attendance in Phase 5). */
    public function enrollments(): HasMany
    {
        return $this->hasMany(ClassEnrollment::class, 'class_id');
    }

    /* ---------------------------------------------------------------
     | Scopes and helpers
     * --------------------------------------------------------------- */

    /**
     * Classes that are still ahead of us (FR-17):
     * status "scheduled" and a date/time in the future, soonest first.
     */
    public function scopeUpcoming(Builder $query): Builder
    {
        $today = now()->toDateString();
        $now = now()->format('H:i:s');

        // whereDate/whereTime compare only the date or the time part, so the
        // result is the same on MySQL and on the SQLite database used by tests.
        return $query->where('status', self::STATUS_SCHEDULED)
            ->where(function (Builder $query) use ($today, $now) {
                $query->whereDate('date', '>', $today)
                    // Same day: the start time must not have passed yet.
                    ->orWhere(function (Builder $query) use ($today, $now) {
                        $query->whereDate('date', $today)->whereTime('time', '>', $now);
                    });
            })
            ->orderBy('date')
            ->orderBy('time');
    }

    /**
     * Hide classes that an administrator has hidden (FR-28).
     */
    public function scopeVisible(Builder $query): Builder
    {
        return $query->where('is_hidden', false);
    }

    /**
     * Phase 2: filter by one of the three statuses.
     */
    public function scopeByStatus(Builder $query, string $status): Builder
    {
        return $query->where('status', $status);
    }

    /**
     * Was this class given by the given teacher?
     */
    public function isOwnedBy(?User $user): bool
    {
        return $user !== null && $this->teacher_id === $user->id;
    }

    /** Is the class running right now? (FR-21) */
    public function isLive(): bool
    {
        return $this->status === self::STATUS_LIVE;
    }

    /**
     * The exact moment the class starts (date + time merged into one Carbon).
     */
    public function startsAt(): Carbon
    {
        // "date" is cast to a Carbon date, "time" stays a plain string.
        $date = $this->date instanceof \DateTimeInterface
            ? $this->date->format('Y-m-d')
            : (string) $this->date;

        $time = $this->time instanceof \DateTimeInterface
            ? $this->time->format('H:i:s')
            : substr((string) $this->time, 0, 8);

        return Carbon::parse($date.' '.$time);
    }

    /** The moment the class ends (start + duration). */
    public function endsAt(): Carbon
    {
        return $this->startsAt()->addMinutes((int) $this->duration);
    }

    /**
     * Phase 2 accessor: {{ $classRoom->start_datetime }}.
     * Returns the merged date + time as a Carbon instance.
     */
    public function getStartDateTimeAttribute(): Carbon
    {
        return $this->startsAt();
    }

    /**
     * Has the class not started yet?
     */
    public function isInTheFuture(): bool
    {
        return $this->startsAt()->isFuture();
    }

    /**
     * Short timing hint for a class card (FR-21): "Live now",
     * "Starts in 2h 15m" or "Ended". No JavaScript needed, so the card stays
     * readable on a slow connection.
     */
    public function timelineLabel(): string
    {
        if ($this->isLive()) {
            return __('Live now');
        }

        // A class the teacher ended (or that the scheduler closed) is over.
        if ($this->status === self::STATUS_COMPLETED) {
            return __('Ended');
        }

        if ($this->startsAt()->isFuture()) {
            return __('Starts in :time', ['time' => $this->humanGap($this->startsAt())]);
        }

        // Still scheduled but its slot has already passed.
        return __('Ended');
    }

    /**
     * Blade-friendly accessor: {{ $classRoom->timeline_label }}.
     * Mirrors timelineLabel() so views and tests can use either the method or
     * the property without duplicating the wording rules (FR-21).
     */
    public function getTimelineLabelAttribute(): string
    {
        return $this->timelineLabel();
    }

    /**
     * "2h 15m" style gap between now and the given moment.
     * Deliberately coarse: the card only needs a hint, not the seconds.
     */
    private function humanGap(Carbon $moment): string
    {
        // "true" asks for the absolute value, which is the same on Carbon 2 and 3.
        $minutes = (int) now()->diffInMinutes($moment, true);

        $parts = [];

        if ($minutes >= 1440) {
            $parts[] = intdiv($minutes, 1440).'d';
        }

        if (intdiv($minutes % 1440, 60) > 0) {
            $parts[] = intdiv($minutes % 1440, 60).'h';
        }

        if ($minutes % 60 > 0) {
            $parts[] = ($minutes % 60).'m';
        }

        return $parts === [] ? '< 1m' : implode(' ', $parts);
    }

    /* ---------------------------------------------------------------
     | Status transitions (FR-21)
     * --------------------------------------------------------------- */

    /**
     * The statuses this class may move to next.
     *
     * @return list<string>
     */
    public function allowedTransitions(): array
    {
        return self::TRANSITIONS[$this->status] ?? [];
    }

    /**
     * May the class switch to the given status?
     */
    public function canTransitionTo(string $status): bool
    {
        return in_array($status, $this->allowedTransitions(), true);
    }

    /* ---------------------------------------------------------------
     | Jitsi room (FR-19)
     * --------------------------------------------------------------- */

    /**
     * A new room name nobody can guess: "educonnect-" plus 20 random
     * characters. The loop guarantees the name is not used yet, and the
     * unique index on the column is the final safety net.
     */
    public static function generateRoomName(): string
    {
        do {
            $name = 'educonnect-'.Str::random(20);
        } while (static::query()->where('room_name', $name)->exists());

        return $name;
    }
}
```

### `app/Http/Controllers/ClassController.php`

```php
<?php

namespace App\Http\Controllers;

use App\Http\Requests\StoreClassRequest;
use App\Http\Requests\UpdateClassRequest;
use App\Models\ClassRoom;
use App\Models\User;
use App\Notifications\NewClassFromFollowedTeacher;
use Illuminate\Http\RedirectResponse;
use Illuminate\Http\Request;
use Illuminate\View\View;

/**
 * A teacher manages their own live classes here (FR-15, FR-16, FR-21).
 * Create, list, edit, delete and the list of enrolled students.
 */
class ClassController extends Controller
{
    /** Classes per page. */
    private const PER_PAGE = 12;

    /** Students per page on the enrolled students page. */
    private const STUDENTS_PER_PAGE = 20;

    /**
     * "My classes": everything this teacher created, newest first.
     * A teacher can narrow the list to one status (FR-15).
     */
    public function index(Request $request): View
    {
        $status = $request->query('status');
        $status = is_string($status) && in_array($status, ClassRoom::STATUSES, true)
            ? $status
            : '';

        $classes = $request->user()->classes()
            // withCount keeps the card free of one query per class (no N+1).
            ->withCount('students')
            ->when($status !== '', fn ($query) => $query->byStatus($status))
            ->orderByRaw("CASE status WHEN 'live' THEN 0 WHEN 'scheduled' THEN 1 ELSE 2 END")
            ->orderBy('date')
            ->orderBy('time')
            ->paginate(self::PER_PAGE)
            ->withQueryString();

        return view('classes.index', [
            'classes' => $classes,
            'status' => $status,
        ]);
    }

    /**
     * The "create a class" form.
     */
    public function create(): View
    {
        return view('classes.create');
    }

    /**
     * Store a new class and give it a hard to guess Jitsi room (FR-19).
     */
    public function store(StoreClassRequest $request): RedirectResponse
    {
        $classRoom = $request->user()->classes()->create([
            ...$request->validated(),
            // Never trust the client for the room name.
            'room_name' => ClassRoom::generateRoomName(),
            'status' => ClassRoom::STATUS_SCHEDULED,
        ]);

        // Everybody who follows this teacher gets a heads up (FR-23).
        $this->notifyFollowers($request->user(), $classRoom);

        return redirect()
            ->route('classes.show', $classRoom)
            ->with('success', __('Your class has been created.'));
    }

    /**
     * Queue a notification for each follower of the teacher (FR-23).
     * Blocked accounts receive nothing.
     */
    private function notifyFollowers(User $teacher, ClassRoom $classRoom): void
    {
        $teacher->followers()
            ->where('users.is_blocked', false)
            ->get()
            ->each(static fn (User $follower) => $follower->notify(
                new NewClassFromFollowedTeacher($teacher, $classRoom)
            ));
    }

    /**
     * The edit form. ClassPolicy decides who gets here (FR-16).
     */
    public function edit(ClassRoom $classRoom): View
    {
        $this->authorize('update', $classRoom);

        return view('classes.edit', ['classRoom' => $classRoom]);
    }

    /**
     * Save the changes to a class.
     */
    public function update(UpdateClassRequest $request, ClassRoom $classRoom): RedirectResponse
    {
        $this->authorize('update', $classRoom);

        // room_name and status are not part of validated(), so they stay as they are.
        $classRoom->update($request->validated());

        return redirect()
            ->route('classes.show', $classRoom)
            ->with('success', __('Your class has been updated.'));
    }

    /**
     * Delete a class. Enrollments disappear through the cascade rule (FR-16).
     */
    public function destroy(ClassRoom $classRoom): RedirectResponse
    {
        $this->authorize('delete', $classRoom);

        $classRoom->delete();

        return redirect()
            ->route('classes.index')
            ->with('success', __('Your class has been deleted.'));
    }

    /**
     * Everybody who enrolled in this class (FR-29).
     * Only the teacher of the class (or an admin) may look at this.
     */
    public function students(ClassRoom $classRoom): View
    {
        $this->authorize('update', $classRoom);

        $classRoom->load('teacher:id,name,subject')->loadCount('students');

        $students = $classRoom->students()
            ->orderBy('name')
            ->paginate(self::STUDENTS_PER_PAGE)
            ->withQueryString();

        return view('classes.students', [
            'classRoom' => $classRoom,
            'students' => $students,
        ]);
    }
}
```

```php
    /**
     * Upcoming (and currently running) classes, with a search box and a
     * subject + teacher filter (FR-17).
     */
    public function index(Request $request): View
    {
        $search = trim((string) $request->query('q'));
        $subject = $request->query('subject');
        $teacher = $request->query('teacher');
        $date = trim((string) $request->query('date'));

        // Anything that is not YYYY-MM-DD is ignored instead of erroring.
        $date = preg_match('/^\d{4}-\d{2}-\d{2}$/', $date) === 1 ? $date : '';

        // Anything that is not a positive integer is ignored as well.
        $teacher = is_scalar($teacher) && ctype_digit((string) $teacher) && (int) $teacher > 0
            ? (int) $teacher
            : 0;

        $query = ClassRoom::query()
            ->visible()
            ->with('teacher:id,name,subject')
            ->withCount('students');

        // Search in the title, in the subject and in the teacher's name.
        if ($search !== '') {
            $query->where(function (Builder $inner) use ($search): void {
                $inner->where('title', 'like', '%'.$search.'%')
                    ->orWhere('subject', 'like', '%'.$search.'%')
                    ->orWhereHas('teacher', fn (Builder $teacher) => $teacher->where('name', 'like', '%'.$search.'%'));
            });
        }

        // Filter on one subject.
        if (is_string($subject) && $subject !== '') {
            $query->where('subject', $subject);
        }

        // Filter on one teacher.
        if ($teacher > 0) {
            $query->where('teacher_id', $teacher);
        }

        // Filter on one calendar day.
        if ($date !== '') {
            $query->whereDate('date', $date);
        }

        // Only classes that are running right now or still ahead of us.
        $query->where(function (Builder $inner): void {
            $inner->where('status', ClassRoom::STATUS_LIVE)
                ->orWhere(fn (Builder $soon) => $soon->upcoming());
        });

        $classes = $query
            ->orderBy('date')
            ->orderBy('time')
            ->paginate(self::PER_PAGE)
            ->withQueryString();

            'classes' => $classes,
            'subjects' => $this->subjects(),
            'teachers' => $this->teachers(),
            'search' => $search,
```

```php
<?php

namespace App\Policies;

use App\Models\ClassRoom;
use App\Models\User;

/**
 * Authorization for live classes (FR-18, FR-20, FR-24, FR-28).
 * Laravel discovers this class automatically because it is called
 * ClassPolicy and lives next to the ClassRoom model namespace.
 */
class ClassPolicy
{
    /**
     * Who may read the class page? Everybody, unless an admin hid it (FR-28).
     * A hidden class stays visible for its own teacher and for admins.
     */
    public function view(User $user, ClassRoom $classRoom): bool
    {
        return ! $classRoom->is_hidden
            || $user->isAdmin()
            || $classRoom->teacher_id === $user->id;
    }

    /**
     * Only the teacher who created the class may change it. Admins keep
     * moderation rights over everything.
     */
    public function update(User $user, ClassRoom $classRoom): bool
    {
        return $classRoom->teacher_id === $user->id || $user->isAdmin();
    }

    /**
     * Same rule for deleting a class (FR-18).
     */
    public function delete(User $user, ClassRoom $classRoom): bool
    {
        return $this->update($user, $classRoom);
    }

    /**
     * Switching between scheduled / live / completed (FR-24).
     */
    public function changeStatus(User $user, ClassRoom $classRoom): bool
    {
        return $this->update($user, $classRoom);
    }

    /**
     * Who may open the live room (FR-20)?
     * Exactly the teacher who owns the class and the students enrolled in it.
     * Admins are moderators, not participants: they hide or delete a class
     * from the admin panel instead of entering a room with minors.
     * A class hidden by an admin is closed to everybody (FR-28).
     */
    public function join(User $user, ClassRoom $classRoom): bool
    {
        // Moderation: a hidden class cannot be joined by anybody.
        if ($classRoom->is_hidden) {
            return false;
        }

        // The teacher who owns the class.
        if ($classRoom->teacher_id === $user->id) {
            return true;
        }

        // Everybody else has to be an enrolled student of this class.
        return $classRoom->students()->whereKey($user->id)->exists();
    }
}
```

```php
            'description' => ['nullable', 'string', 'max:2000'],
            'subject' => ['nullable', 'string', 'max:100'],
            'date' => ['required', 'date', 'after_or_equal:today'],
            'time' => ['required', 'date_format:H:i'],
            // A class lasts between 15 minutes and 4 hours.
            'duration' => ['required', 'integer', 'min:15', 'max:240'],
        ];
    }

    /**
     * The browser sends "14:30" from <input type="time">, but a form that was
     * filled in by hand may send "14:30:00". Cut both down to H:i.
     */
    protected function prepareForValidation(): void
    {
        if ($this->filled('time')) {
            $this->merge(['time' => substr((string) $this->input('time'), 0, 5)]);
        }
    }

    /**
     * Reject a class that would start in the past (FR-15).
     */
    public function withValidator(Validator $validator): void
    {
        $validator->after(function (Validator $validator): void {
            // Only check the date/time combination when both parts are valid.
            if ($validator->errors()->has('date') || $validator->errors()->has('time')) {
                return;
            }

            $startsAt = $this->startsAt();

            if ($startsAt !== null && $startsAt->isPast()) {
                $validator->errors()->add('time', __('A new class has to start in the future.'));
            }
        });
    }

    /**
     * @return array<string, string>
     */
    public function messages(): array
    {
        return [
            'title.required' => __('Give your class a title.'),
            'date.after_or_equal' => __('The class cannot be planned in the past.'),
            'time.date_format' => __('Enter the start time as HH:MM.'),
            'duration.min' => __('A class lasts at least 15 minutes.'),
            'duration.max' => __('A class lasts at most 4 hours.'),
        ];
    }

    /**
     * The start moment, or null when the input cannot be understood.
     */
    private function startsAt(): ?Carbon
    {
        try {
            return Carbon::createFromFormat(
                'Y-m-d H:i',
                $this->input('date').' '.$this->input('time')
            );
        } catch (\Throwable) {
            return null;
```

```php
namespace App\Console\Commands;

use App\Models\ClassRoom;
use App\Notifications\ClassStartingSoon;
use Illuminate\Console\Command;
use Illuminate\Support\Carbon;

/**
 * FR-23: remind the teacher and the enrolled students a few minutes before a
 * class starts.
 *
 * The scheduler calls this command every minute (see routes/console.php).
 * The "starting_soon_notified_at" column is the flag that makes sure a class
 * is announced exactly once: it is written in the same pass that queues the
 * notifications, and only rows with a NULL flag are picked up.
 */
class NotifyClassesStartingSoon extends Command
{
    /**
     * @var string
     */
    protected $signature = 'classes:notify-starting-soon {--minutes=15 : How far ahead to look}';

    /**
     * @var string
     */
    protected $description = 'Notify the teacher and enrolled students of classes starting in the next 15 minutes';

    public function handle(): int
    {
        $from = now();
        $until = now()->addMinutes((int) $this->option('minutes'));

        // Cheapest possible pre-filter: only scheduled, visible classes on the
        // right day that were never announced. The exact minute is then checked
        // in PHP, which behaves the same on MySQL and on SQLite (tests).
        $candidates = ClassRoom::query()
            ->visible()
            ->where('status', ClassRoom::STATUS_SCHEDULED)
            ->whereNull('starting_soon_notified_at')
            ->whereDate('date', '>=', $from->toDateString())
            ->whereDate('date', '<=', $until->toDateString())
            ->with(['teacher', 'students'])
            ->get();

        $notified = 0;

        foreach ($candidates as $classRoom) {
            if (! $this->startsWithin($classRoom, $from, $until)) {
                continue;
            }

            // Enrolled students first, then the teacher who runs the class.
            foreach ($classRoom->students as $student) {
                $student->notify(new ClassStartingSoon($classRoom));
            }

            $classRoom->teacher?->notify(new ClassStartingSoon($classRoom));

            // One shot: the flag keeps the reminder from being sent again.
            $classRoom->forceFill(['starting_soon_notified_at' => now()])->save();

            $notified++;
        }

        $this->info("Starting-soon notifications queued for {$notified} class(es).");

        return self::SUCCESS;
    }

    /**
     * Does the class start between $from and $until?
     */
    private function startsWithin(ClassRoom $classRoom, Carbon $from, Carbon $until): bool
    {
        $startsAt = $classRoom->startsAt();

        return $startsAt->greaterThanOrEqualTo($from) && $startsAt->lessThanOrEqualTo($until);
    }
}
```

```php
        if (! $nextClass) {
            $nextClass = $upcomingClasses->first();
        }

        $heroClass = $nextClass?->load([
            'students' => fn ($query) => $query->orderBy('name')->limit(6),
        ]);

        $followingIds = $student->following()->pluck('users.id');

        $charts = $metrics->studentCharts($student, '12m');

        return view('dashboards.student', [
            'stats' => $metrics->studentStats($student),
            'upcomingClasses' => $upcomingClasses,
            'recommendedTeachers' => $this->recommendedTeachers($student),
            'recommendedClasses' => $this->recommendedClasses($student),
            'heroClass' => $heroClass,
            'classmates' => $heroClass?->students ?? collect(),
            'followingIds' => $followingIds,
            'notificationCount' => $student->unreadNotifications()->count(),
            'activityChart' => $charts['activity'],
            'feedPreview' => $this->feedPreview($student),
        ]);
    }

    /**
     * Teachers that this student does not follow yet, most followed first.
     *
     * @return EloquentCollection<int, User>
     */
    private function recommendedTeachers(User $student): EloquentCollection
    {
        // Sub-query of everybody the student already follows.
        $alreadyFollowed = Follow::query()
            ->select('following_id')
            ->where('follower_id', $student->id);

        return User::query()
            ->where('role', User::ROLE_TEACHER)
            ->whereNotIn('users.id', $alreadyFollowed)
            ->withCount('followers')
            ->orderByDesc('followers_count')
            ->orderBy('name')
            ->limit(self::RECOMMENDATION_LIMIT)
            ->get();
    }

    /**
     * Classes from followed teachers or from subjects the student already
     * studies, excluding anything they are enrolled in.
     *
     * @return EloquentCollection<int, ClassRoom>
     */
    private function recommendedClasses(User $student): EloquentCollection
    {
        $followedTeacherIds = $student->following()
            ->where('users.role', User::ROLE_TEACHER)
            ->pluck('users.id');

        $subjects = $student->enrolledClasses()
            ->whereNotNull('classes.subject')
            ->distinct()
            ->pluck('classes.subject');

        if ($followedTeacherIds->isEmpty() && $subjects->isEmpty()) {
            return new EloquentCollection;
        }

        $enrolledIds = $student->enrolledClasses()->select('classes.id');

        return ClassRoom::query()
            ->visible()
            ->upcoming()
            ->whereNotIn('classes.id', $enrolledIds)
            ->where(function ($query) use ($followedTeacherIds, $subjects): void {
                if ($followedTeacherIds->isNotEmpty()) {
                    $query->whereIn('teacher_id', $followedTeacherIds);
                }

                if ($subjects->isNotEmpty()) {
                    $query->orWhereIn('subject', $subjects);
                }
            })
            ->with('teacher:id,name,subject,photo')
            ->withCount('students')
            ->limit(self::CLASS_RECOMMENDATION_LIMIT)
            ->get();
    }

    /**
     * The newest posts from people the student follows.
     *
     * @return EloquentCollection<int, Post>
     */
    private function feedPreview(User $student): EloquentCollection
    {
        $following = $student->following()->pluck('users.id');

        if ($following->isEmpty()) {
            return new EloquentCollection;
        }

        return Post::query()
            ->visible()
            ->whereIn('user_id', $following)
            ->withFeedData($student)
            ->latest()
            ->limit(self::FEED_PREVIEW_LIMIT)
            ->get();
    }
```

```php
        // My classes, newest first, with the number of enrolled students.
        // withCount() keeps the table free of N+1 queries.
        $classes = $mine
            ->withCount('students')
            ->orderByDesc('date')
            ->orderByDesc('time')

     * Each source is limited to ACTIVITY_LIMIT rows and eager loads its author,

     *
     * @return Collection<int, array{icon: string, color: string, text: string, excerpt: string|null, at: CarbonInterface|null}>

    private function recentActivity(User $teacher): Collection

        $likes = Like::query()
            ->with(['user:id,name', 'post:id,user_id,body'])
            ->whereHas('post', fn ($query) => $query->where('user_id', $teacher->id))

                'color' => 'primary',

                'at' => $like->created_at,

        $comments = Comment::query()
            ->with(['user:id,name', 'post:id,user_id,body'])
            ->whereHas('post', fn ($query) => $query->where('user_id', $teacher->id))

            ->get()
            ->map(fn (Comment $comment) => [
                'icon' => 'bi-chat',
                'color' => 'success',
                'text' => __(':name commented on your post', ['name' => $comment->user?->name ?? __('Someone')]),
                'excerpt' => $comment->body,
                'at' => $comment->created_at,
            ]);

        // Students who enrolled in one of my classes.
        $enrollments = ClassEnrollment::query()
            ->with(['student:id,name', 'classRoom:id,teacher_id,title'])
            ->whereHas('classRoom', fn ($query) => $query->where('teacher_id', $teacher->id))
            ->latest()
            ->limit(self::ACTIVITY_LIMIT)
            ->get()
            ->map(fn (ClassEnrollment $enrollment) => [
                'icon' => 'bi-person-check',
                'color' => 'info',
                'text' => __(':name enrolled in :class', [
                    'name' => $enrollment->student?->name ?? __('Someone'),
                    'class' => $enrollment->classRoom?->title ?? __('your class'),
                ]),
                'excerpt' => null,
                'at' => $enrollment->created_at,
            ]);

        // People who started following me.
        $followers = Follow::query()
            ->with('follower:id,name')
            ->where('following_id', $teacher->id)
            ->latest()
            ->limit(self::ACTIVITY_LIMIT)
            ->get()
            ->map(fn (Follow $follow) => [
                'icon' => 'bi-person-plus',
                'color' => 'warning',
                'text' => __(':name started following you', ['name' => $follow->follower?->name ?? __('Someone')]),
                'excerpt' => null,
                'at' => $follow->created_at,
            ]);

        return $likes
            ->concat($comments)
            ->concat($enrollments)
            ->concat($followers)
            ->sortByDesc('at')
            ->take(self::ACTIVITY_LIMIT)
            ->values();
    }
```

```php
    public function normalizeRange(?string $range): string
    {
        return in_array($range, self::RANGES, true) ? $range : '12m';
    }

    /**
     * @return array{labels: list<string>, values: list<int>, total: int}
     */
    private function seriesForRange(Collection $timestamps, string $range): array
    {
        return match ($range) {
            '7d' => $this->daySeries($timestamps, 7),
            '30d' => $this->weekSeries($timestamps, 5),
            default => $this->monthSeries($timestamps, 12),
        };
    }

    /**
     * @return array{labels: list<string>, values: list<int>, total: int}
     */
    private function daySeries(Collection $timestamps, int $days): array
    {
        $start = now()->copy()->startOfDay()->subDays($days - 1);
        $counts = $timestamps->countBy(
            static fn ($timestamp) => Carbon::parse($timestamp)->toDateString()
        );

        $labels = [];
        $values = [];

        for ($offset = 0; $offset < $days; $offset++) {
            $day = $start->copy()->addDays($offset);

            $labels[] = $day->format('d M');
            $values[] = (int) ($counts[$day->toDateString()] ?? 0);
        }

        return ['labels' => $labels, 'values' => $values, 'total' => array_sum($values)];
    }

    /**
     * @return array{labels: list<string>, values: list<int>, total: int}
     */
    private function weekSeries(Collection $timestamps, int $weeks): array
    {
        $start = now()->copy()->startOfWeek()->subWeeks($weeks - 1);
        $counts = $timestamps->countBy(
            static fn ($timestamp) => Carbon::parse($timestamp)->startOfWeek()->toDateString()
        );

        $labels = [];
        $values = [];

        for ($offset = 0; $offset < $weeks; $offset++) {
            $week = $start->copy()->addWeeks($offset);

            $labels[] = $week->format('d M');
            $values[] = (int) ($counts[$week->toDateString()] ?? 0);
        }

        return ['labels' => $labels, 'values' => $values, 'total' => array_sum($values)];
    }

    /**
     * @return array{labels: list<string>, values: list<int>, total: int}
     */
    private function monthSeries(Collection $timestamps, int $months): array
    {
        // First month of the window: 11 months back, so today's month is included.
        $start = now()->copy()->startOfMonth()->subMonths($months - 1);
        $counts = $timestamps->countBy(
            static fn ($timestamp) => Carbon::parse($timestamp)->format('Y-m')
        );

        $labels = [];
        $values = [];

        for ($offset = 0; $offset < $months; $offset++) {
            $month = $start->copy()->addMonths($offset);

            $labels[] = $month->format('M Y');
            $values[] = (int) ($counts[$month->format('Y-m')] ?? 0);
        }

        return ['labels' => $labels, 'values' => $values, 'total' => array_sum($values)];
    }

    private function rangeStart(string $range): Carbon
    {
        return match ($range) {
            '7d' => now()->copy()->startOfDay()->subDays(6),
            '30d' => now()->copy()->startOfDay()->subDays(29),
            default => now()->copy()->startOfMonth()->subMonths(11),
        };
    }

    /**
     * @return array{percent: int, direction: string}
     */
    private function trend(int $current, int $previous): array
    {
        if ($previous === 0) {
            $percent = $current === 0 ? 0 : 100;
        } else {
            $percent = (int) round((($current - $previous) / $previous) * 100);
        }

        return [
            'percent' => $percent,
            'direction' => $percent > 0 ? 'up' : ($percent < 0 ? 'down' : 'flat'),
        ];
    }
}
```

```php
<?php

namespace App\Http\Middleware;

use Closure;
use Illuminate\Http\Request;
use Symfony\Component\HttpFoundation\Response;

/**
 * Baseline security headers for every web response (SRS 5.2).
 * The Jitsi room needs a different policy because it embeds meet.jit.si.
 */
class SecurityHeaders
{
    public function handle(Request $request, Closure $next): Response
    {
        $response = $next($request);

        $response->headers->set('X-Content-Type-Options', 'nosniff');
        $response->headers->set('Referrer-Policy', 'strict-origin-when-cross-origin');
        $response->headers->set('X-XSS-Protection', '0');
        $response->headers->remove('X-Powered-By');

        $isJitsiRoom = $request->routeIs('classes.room');
        $jitsiDomain = config('services.jitsi.domain', 'meet.jit.si');

        if ($isJitsiRoom) {
            // The video room is embedded from another origin, so the page must
            // not forbid framing and must allow camera + microphone there.
            $response->headers->remove('X-Frame-Options');
            $response->headers->set(
                'Content-Security-Policy',
                "frame-src 'self' https://{$jitsiDomain};"
            );
            $response->headers->set(
                'Permissions-Policy',
                "camera=(self \"https://{$jitsiDomain}\"), ".
                "microphone=(self \"https://{$jitsiDomain}\"), ".
                "display-capture=(self \"https://{$jitsiDomain}\")"
            );
        } else {
            $response->headers->set('X-Frame-Options', 'SAMEORIGIN');
            $response->headers->set(
                'Permissions-Policy',
                'camera=(), microphone=(), geolocation=()'
            );
        }

        if (app()->isProduction() && $request->isSecure()) {
            $response->headers->set(
                'Strict-Transport-Security',
                'max-age=31536000; includeSubDomains'
            );
        }

        return $response;
    }
}
```

```php
|
```

```php
|
| On Windows you can simulate the same thing by running
|   php artisan schedule:work
```

```javascript
/**
 * EduConnect live class room (FR-18, FR-20, FR-22).
 *
 * The page does not contain an iframe: it carries the room settings in data-*
 * attributes and this file asks the Jitsi Meet External API to build the room
 * (video, audio, screen sharing and the built in chat all come from Jitsi).
 *
 * Two things have to keep working on a bad connection:
 *   1. the API script may fail to load or time out -> friendly message + retry,
 *   2. the user may end the call from inside Jitsi -> back to the dashboard.
 */

/** Give up on the External API after this long (a school network can hang). */
const SCRIPT_TIMEOUT_MS = 15000;

/** How long we wait after "hangup" before leaving the page. */
const LEAVE_DELAY_MS = 1200;

/** The JitsiMeetExternalAPI instance; needed to close the room on a retry. */
let api = null;

/** Guards against a double redirect when hangup and readyToClose both fire. */
let leaving = false;

/**
 * Load the External API script once and resolve when window.JitsiMeetExternalAPI
 * exists. Rejects on a network error, a missing global or a timeout.
 */
function loadExternalApi(url) {
    return new Promise((resolve, reject) => {
        if (window.JitsiMeetExternalAPI) {
            resolve();
            return;
        }

        const script = document.createElement('script');
        script.src = url;
        script.async = true;
        script.dataset.jitsiApi = '1';

        // Without a timeout a hanging request would leave the spinner forever.
        const timer = window.setTimeout(() => {
            script.remove();
            reject(new Error('timeout'));
        }, SCRIPT_TIMEOUT_MS);

        script.addEventListener('load', () => {
            window.clearTimeout(timer);
            if (window.JitsiMeetExternalAPI) {
                resolve();
            } else {
                reject(new Error('api-missing'));
            }
        });

        script.addEventListener('error', () => {
            window.clearTimeout(timer);
            reject(new Error('network'));
        });

        document.head.appendChild(script);
    });
}

/** Leave the page and go back to the class detail page (FR-20 edge case). */
function leaveRoom(leaveUrl) {
    if (leaving) {
        return;
    }

    leaving = true;
    window.setTimeout(() => {
        window.location.href = leaveUrl;
    }, LEAVE_DELAY_MS);
}

/**
 * Build the Jitsi room for one [data-jitsi] wrapper.
 */
async function startRoom(wrapper) {
    const container = wrapper.querySelector('[data-jitsi-container]');
    const status = wrapper.querySelector('[data-jitsi-status]');
    const errorBox = wrapper.querySelector('[data-jitsi-error]');

    const showError = () => {
        status?.classList.add('d-none');
        errorBox?.classList.remove('d-none');
    };

    // Reset the UI so a retry starts from a clean state.
    errorBox?.classList.add('d-none');
    status?.classList.remove('d-none');

    if (container) {
        container.innerHTML = '';
    }

    // Close a room that is still open from a previous attempt.
    if (api) {
        try {
            api.dispose();
        } catch (error) {
            console.warn('[EduConnect] could not dispose the previous room', error);
        }
        api = null;
    }

    try {
        await loadExternalApi(wrapper.dataset.scriptUrl);
    } catch (error) {
        console.error('[EduConnect] the Jitsi External API did not load', error);
        showError();
        return;
    }

    const options = {
        roomName: wrapper.dataset.room,
        parentNode: container,
        width: '100%',
        height: '100%',
        // Jitsi shows these next to every message and in the participant list.
        userInfo: {
            displayName: wrapper.dataset.displayName,
            email: wrapper.dataset.email,
            avatarUrl: wrapper.dataset.avatar,
        },
        configOverwrite: {
            // Teacher-friendly defaults: the moderator starts unmuted with the
            // camera on. Students start muted so they can look around first.
            startWithVideoMuted: wrapper.dataset.moderator !== '1',
            startWithAudioMuted: wrapper.dataset.moderator !== '1',
            // Show the preview screen so a student can check the microphone first.
            prejoinPageEnabled: true,
            // Keeps mobile browsers on the page instead of opening the app.
            disableDeepLinking: true,
            // The class title is the meeting subject shown in the room.
            subject: wrapper.dataset.subject,
            // Exactly the buttons the brief asks for: microphone, camera,
            // chat, raise hand, tile view, fullscreen and hang up.
            toolbarButtons: [
                'microphone',
                'camera',
                'chat',
                'raisehand',
                'tileview',
                'fullscreen',
                'hangup',
            ],
        },
        interfaceConfigOverwrite: {
            SHOW_JITSI_WATERMARK: false,
            MOBILE_APP_PROMO: false,
            DEFAULT_BACKGROUND: '#f6f7fb',
        },
    };

    try {
        api = new window.JitsiMeetExternalAPI(wrapper.dataset.domain, options);
    } catch (error) {
        console.error('[EduConnect] Jitsi refused to start the room', error);
        showError();
        return;
    }

    // The spinner can go as soon as the user is inside the room.
    api.addEventListener('videoConferenceJoined', () => {
        status?.classList.add('d-none');
    });

    // The red phone inside Jitsi: back to the class page with a flash message.
    api.addEventListener('hangup', () => {
        leaveRoom(wrapper.dataset.leaveUrl);
    });

    // Fired after the room was closed from the Jitsi side.
    api.addEventListener('readyToClose', () => {
        leaveRoom(wrapper.dataset.leaveUrl);
    });

    // A failed conference (wrong room, server down) must not look like a hang.
    api.addEventListener('errorOccurred', (event) => {
        console.error('[EduConnect] Jitsi reported an error', event);
        showError();
    });
}

/** Wire every room on the page (there is only one, but this stays reusable). */
function initJitsiRooms() {
    document.querySelectorAll('[data-jitsi]').forEach((wrapper) => {
        startRoom(wrapper);

        // Retry button shown when the script could not be loaded.
        wrapper.querySelector('[data-jitsi-retry]')?.addEventListener('click', () => {
            startRoom(wrapper);
        });
    });
}

if (document.readyState === 'loading') {
    document.addEventListener('DOMContentLoaded', initJitsiRooms);
} else {
    initJitsiRooms();
}
```

```javascript
/**
 * Live preview on the "create / edit a class" form (Phase 3C).
 *
 * While the teacher types, the card on the right mirrors the title, subject,
 * date, time and duration. Only text is updated (textContent), so nothing the
 * teacher writes can become markup. Without JavaScript the preview simply
 * shows the server-rendered starting values.
 */

function formatDate(value) {
    if (!value) {
        return '';
    }

    const date = new Date(`${value}T00:00:00`);

    if (Number.isNaN(date.getTime())) {
        return value;
    }

    return date.toLocaleDateString(undefined, {
        weekday: 'short',
        day: '2-digit',
        month: 'short',
        year: 'numeric',
    });
}

function bootClassPreview() {
    const form = document.querySelector('[data-class-form]');
    const preview = document.querySelector('[data-class-preview]');

    if (!form || !preview) {
        return;
    }

    const title = form.querySelector('#title');
    const subject = form.querySelector('#subject');
    const date = form.querySelector('#date');
    const time = form.querySelector('#time');
    const duration = form.querySelector('#duration');

    const set = (selector, value) => {
        const target = preview.querySelector(selector);

        if (target) {
            target.textContent = value;
        }
    };

    const update = () => {
        set('[data-preview-title]', title?.value.trim() || preview.dataset.emptyTitle || '');
        set('[data-preview-subject]', subject?.value.trim() || preview.dataset.emptySubject || '');
        set('[data-preview-date]', formatDate(date?.value) || preview.dataset.emptyDate || '');
        set('[data-preview-time]', time?.value || preview.dataset.emptyTime || '');
        set(
            '[data-preview-duration]',
            duration?.value ? `${duration.value} ${preview.dataset.durationLabel || 'min'}` : '',
        );

        const subjectChip = preview.querySelector('[data-preview-subject-chip]');
        if (subjectChip) {
            subjectChip.hidden = !subject?.value.trim();
        }
    };

    [title, subject, date, time, duration].forEach((field) => {
        field?.addEventListener('input', update);
        field?.addEventListener('change', update);
    });

    update();
}

if (document.readyState === 'loading') {
    document.addEventListener('DOMContentLoaded', bootClassPreview);
} else {
    bootClassPreview();
}
```

```php
    public function test_every_post_form_carries_a_csrf_token(): void
    {
        // Static audit of the Blade templates: a form that writes must always
        // render @csrf, including the modal/component forms.
        $violations = [];

        foreach (File::allFiles(resource_path('views')) as $file) {
            if (! str_ends_with($file->getFilename(), '.blade.php')) {
                continue;
            }

            $contents = $file->getContents();

            preg_match_all('/<form\b[^>]*>/i', $contents, $matches, PREG_OFFSET_CAPTURE);

            foreach ($matches[0] as [$tag, $offset]) {
                // GET forms (search/filter) do not change state and need no token.
                if (preg_match('/method\s*=\s*["\']?post["\']?/i', $tag) !== 1) {
                    continue;
                }

                $end = strpos($contents, '</form>', $offset);
                $form = $end === false
                    ? substr($contents, $offset)
                    : substr($contents, $offset, $end - $offset);

                if (! str_contains($form, '@csrf')) {
                    $violations[] = $file->getRelativePathname().': '.trim($tag);
                }
            }
        }

        $this->assertSame(
            [],
            $violations,
            "Write forms without @csrf:\n".implode("\n", $violations)
        );
    }
```
